# Third-Party Licenses

Beisammen includes third-party dependencies that remain under their own
licenses. This repository-level file is the place to collect notices for
dependencies that require explicit attribution once the dependency graph is
finalized.

Current policy:

- application code authored in this repository is licensed under PolyForm
  Noncommercial 1.0.0
- third-party npm packages, Expo SDK packages, Convex packages, and WorkOS SDKs
  remain under their own upstream licenses
- generated platform files must not remove or alter upstream license headers

Before the first public release, generate and review a full dependency license
report and append it here or link to an automated report artifact.
