# Contributing

Contributions are welcome through pull requests.

## Rules

- Keep the project source-available and noncommercial in spirit.
- Do not open pull requests that add secrets, live credentials, or production
  identifiers.
- Do not commit Expo owner metadata, EAS project IDs, Clerk secrets, storage
  credentials, or mobile signing material.
- Keep public-vs-secret environment boundaries intact.

## Developer Certificate of Origin

By contributing, you certify that you have the right to submit the work under
the repository license and that each commit includes the following trailer:

```text
Signed-off-by: Your Name <you@example.com>
```

## Workflow

1. Fork the repository.
2. Create a focused branch.
3. Add tests or type coverage where the change warrants it.
4. Submit a pull request with a concise description and the relevant setup
   notes.
