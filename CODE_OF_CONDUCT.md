# Code of Conduct

This project expects respectful, technical, and direct collaboration.

## Expected behavior

- discuss ideas and changes in good faith
- focus criticism on code and decisions, not people
- document assumptions clearly
- respect privacy and security constraints

## Unacceptable behavior

- harassment or personal attacks
- publishing secrets or sensitive user data
- misrepresenting the license or branding rights

Maintainers may remove contributions or participation that materially harms the
project or its contributors.
